Wind Particle Animation Library

Proof of Concept Demos

POC 1: Particle Boundary

WebGL 2 + Rust WASM migration. Particle simulation in Rust, rendered with WebGL point sprites. State machine: active, exiting, respawning.

18 Tests

POC 2: NaN Handling

Wind texture with NaN regions. WindSampler with bilinear interpolation. Background shader shows valid/invalid regions.

23 Tests

POC 3: Wind Trails

TrailManager with shift approach. Quad rendering with alpha fade and width taper.

21 Tests

POC 4: Map Coordinate Sync

World coordinates with pan/zoom. View transform in shader. No WASM changes - modules are coordinate-agnostic.

Reuses POC 3

POC 5: Leaflet Integration

Full Leaflet map with OSM tiles. Zoom-based particle scaling. No WASM changes - reuses all POC 1-4 modules.

Reuses POC 4

POC 6: Dynamic Atlas + Tiles

FixedAtlas with viewport resampling. Tile loading with LRU cache. Auto-load on pan/zoom, performance metrics, mobile support.

40 Tests

POC 7: Unified API

WindAnimation struct combining ParticleSimulator, TrailManager, WindSampler, and TrailVertexBuilder into simple library API.
